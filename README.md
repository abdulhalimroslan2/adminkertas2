# 📊 Admin Suite: Pusat Kawalan & Pemantauan Lesen E-Book Fizik SPM 2026

Laman web dashboard khas untuk penjual Shopee memantau penggunaan kod lesen, baki muat turun, reset kuota, menyekat/menyahaktifkan kod, dan menyalin mesej Shopee Chat dengan 1-klik pantas.

---

## 🌟 Ciri-ciri Utama

1. **Ringkasan KPI Masa Nyata (Live Metrics)**:
   - Jumlah keseluruhan lesen (500 kod)
   - Baki stok belum digunakan (2/2)
   - Kod sedang digunakan oleh pembeli (1/2)
   - Kod yang telah tamat had (0/2)
   - Jumlah keseluruhan muat turun terkumpul

2. **Tindakan Pantas bagi Setiap Kod**:
   - 💬 **Shopee**: 1-Klik salin mesej lengkap berserta link direct auto-tebus ke Shopee Chat pembeli.
   - 🔗 **Link**: Salin pautan terus `https://kertas22026.vercel.app/?key=XXXX`.
   - ➕ **+1 Kuota**: Tambah 1 kuota muat turun jika pembeli hadapi masalah talian.
   - 🔄 **Reset**: Reset kuota kembali penuh kepada 2 kali muat turun.
   - 🚫 **Sekat / Aktif**: Nyahaktifkan kod atau aktifkan semula serta-merta di awan.
   - 🗑️ **Padam**: Padam rekod yang tidak diperlukan.

3. **Bantuan Pantas Pesanan (Quick Assign Assistant)**:
   - Butang **⚡ Ambil 1 Kod Baru (Shopee)** akan automatik memilih kod belum guna yang seterusnya, membolehkan anda memasukkan nama/nombor pesanan pembeli, dan terus menyalin mesej Shopee Chat ke clipboard anda!

4. **Jana Pukal & Eksport CSV**:
   - Jana tambahan 10, 50, 100 kod baharu terus ke Supabase.
   - Muat turun laporan jualan ke fail Excel / CSV.
